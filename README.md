# Instagram Login Page

A simple and responsive Instagram Login Page designed using **HTML and CSS**. This project recreates the basic look and layout of the Instagram login interface for front-end practice and learning purposes.

## 🚀 Features

* Clean and simple user interface
* Responsive design
* Instagram-inspired login layout
* Username/Email and Password input fields
* Login button and supporting links

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📂 Project Structure

```text
Instagram-Login-Page/
├── index.html
├── style.css
└── images/
```

## 🎯 Purpose

This project was created to practice **HTML, CSS, responsive design, and front-end development** by recreating a popular login interface.
